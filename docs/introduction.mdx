# Welcome to JarvisOS ⚡

**Windows 11 was built for consumers. JarvisOS was built for developers.**

JarvisOS is an uncompromising, highly-optimized **AME (Ameliorated) playbook**. It surgically eviscerates Microsoft's telemetry stack, bloated pre-installed apps, and background noise, while perfectly preserving the critical infrastructure that full-stack developers rely on daily: WSL2, Hyper-V, Docker, .NET, WinGet, and Windows Terminal.

> **One baseline. No modes. Zero compromises.**

---
