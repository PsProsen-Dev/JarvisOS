# JarvisOS⚡

Windows 11 was built for consumers. JarvisOS was built for developers.

It is a custom **AME (Ameliorated) playbook** — a deep-system configuration package that surgically removes Microsoft's telemetry stack, bloatware, and background noise, while strictly preserving every tool a full-stack developer needs: WSL2, Hyper-V, Docker, .NET, WinGet, and Windows Terminal.

> **One baseline. No modes. No compromise.**

---

JarvisOS is built for one audience: **full-stack developers** who want Windows out of their way.

JarvisOS presents a full-screen selection UI (Privacy+ style) where you pick your stack:

| Category | Options |
|----------|---------|
| **Browser** | Brave · LibreWolf · Zen Browser |
| **Office Suite** | OnlyOffice · LibreOffice · FreeOffice |
| **Dev Tools** | Git · VS Code · Node.js LTS (all optional) |
| **Maintenance** | Privacy+ Settings · App Fetch · AtlasOS Toolbox · Revision Tool |
